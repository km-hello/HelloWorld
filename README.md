# Three-Body Hello World

一个基于 Three.js 的实时三体视觉实验：三颗光球按照牛顿引力在完整的 `x / y / z` 空间中运动，并从一座位于 `z = 0` 的立体镜面 `HELLO WORLD !` 纪念碑前后穿过。

## 本地运行

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

也可以使用 Docker：

```bash
docker build -t three-body-hello-world .
docker run --rm -p 8080:80 three-body-hello-world
```

## 测试

```bash
npm test
```

测试覆盖三体计算的确定性、质心与总动量校正、近距离软化、双星再交互、离屏回拉、窄屏长时稳定性和异常状态恢复。

## 视觉实现

- `TextGeometry` 生成端正、居中的带倒角立体字，字形本身不应用斜体或纵深斜切；整座纪念碑仅做约 `6.3°` 俯仰和 `8°` 侧转，以露出更多倒角、顶面与侧壁反光。文字中心位于世界坐标 `z = 0`，真实深度测试会让后方光球被文字遮挡，前方光球自然盖过文字。
- 字面使用 `metalness = 1` 的 `MeshPhysicalMaterial`，以 GGX 高光和动态环境贴图生成镜面，不叠加固定渐变。主场景和反射捕获背景均为纯黑，且没有环境光、方向光或隐藏反射板；`CubeCamera` 只捕获光球与轨迹，因此彩色反射完全随三体运动实时改变。反射捕获使用独立的光球代理，并限制其相对捕获相机的最大角尺寸；贴近镜面中心时平滑淡出，避免单颗光球铺满立方体贴图而令整面文字瞬间全亮。
- 镜面立方体贴图使用固定 `64px` 面尺寸；桌面逐帧更新，窄屏或内存受限设备隔帧更新，以控制六面渲染的性能成本。
- 三颗光球保持原版“双层精灵”样式：每种颜色分别预生成柔和外晕与白亮核心，不使用硬边三维球壳。远景外晕和核心保留 `0.46 / 0.58` 的透明度下限，近景再随纵深平滑增强；三种颜色使用加法混合，重叠时会自然生成综合色。
- 每颗光球使用 40 点固定容量轨迹缓冲；轨迹和光球都会进入动态反射捕获。双层精灵只负责可见光晕，真正照亮文字的是位于球心、向所有方向发光的 `PointLight`。光源功率不随相机距离改变，`decay = 2` 且没有人为距离截断；镜面上的三色贡献按平方反比衰减后共同累加，因此远处微弱但不突然熄灭。
- Z 轴纵深强化仅存在于渲染层：视觉映射增益为 `3.1×`，透视范围限制在 `0.44–2.18`，光球自身尺寸系数从远处的 `0.58` 过渡到近处的 `1.4`，形成明显的远小近大与扑面效果。
- 物理系统、Z 坐标、速度和引力参数没有因视觉强化而改变。离屏恢复仍使用独立且更保守的 `2.1×` 投影，视觉夸张不会反向改变运动规则。
- 当前镜面属于实时 PBR 近似：Three.js 会把动态立方体贴图预过滤后交给物理材质，但整行文字共用一个中心反射探针，并用受控代理处理近距离发光体；它比固定渐变真实，但不是逐像素光线追踪或路径追踪。
- 页面隐藏时暂停计算；返回时清空时间累积。开启 `prefers-reduced-motion` 时保留静态构图。
- WebGL 初始化失败时会回退到可读的 DOM 文字，不留下空白页面。

## 物理实现

- `physics.js` 使用固定 `1/120s` 步长的 Velocity Verlet 积分计算三维引力。
- 三条可见轨迹以 `30Hz` 直接采样同一组物理位置；渲染代码不改写位置或速度，只在输出时进行世界缩放和 Z 轴视觉映射。
- 默认初态保持零总动量；有限尺寸排斥核避免极近距离三球重合，同时保留掠过和引力弹弓。
- 核心活动区以三体引力为主，软边界只在物体离开主要活动范围后逐步介入。
- 紧密双星只有在持续满足束缚和隔离条件后才进入再交互阶段；控制只改变成对力的强度，不直接改写速度。
- 离屏保护根据持续时间、运动方向和返回进度渐进触发，正常回程不会被突然重置。
- 因为包含软化、有限尺寸排斥核、软边界、离屏回拉、速度上限和持久双星再交互控制，这是一套面向长时间视觉稳定性的三体模型，并非完全孤立、无限空间中的点质量牛顿系统。关闭这些保护后的经典八字轨道回归测试会单独验证积分器的能量、动量与质心稳定性。

主要物理参数集中在 `physics.js` 的 `DEFAULT_PHYSICS_CONFIG`；视口缩放与离屏进度跟踪位于 `viewport.js`；相机、视觉纵深、镜面反射和渲染生命周期参数位于 `app.js`。

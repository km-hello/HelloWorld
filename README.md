# Three-Body Hello World

一个零运行时依赖的静态页面：三个光球在完整的 `x / y / z` 三维空间中按照牛顿引力运动，并通过 Canvas 透视投影从轻量的 `Hello World` 字标前方穿过。

## 本地运行

浏览器的 ES Module 需要通过 HTTP 加载。在项目目录启动任意静态服务器，例如：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

也可以使用 Docker：

```bash
docker build -t three-body-hello-world .
docker run --rm -p 8080:80 three-body-hello-world
```

## 测试

项目没有第三方 JavaScript 依赖，物理测试使用 Node.js 内置测试运行器：

```bash
npm test
```

测试覆盖确定性、质心与总动量校正、近距离软化、离屏回拉、窄屏长时稳定性和异常状态恢复。

## 实现说明

- `physics.js` 使用固定 `1/120s` 步长的 Velocity Verlet 积分计算三维引力。
- 默认初态保留零总动量，同时将初始速度幅度提高约 20%；在 `1280×720` 视口中，第一次接近屏幕边缘从数分钟提前到约 10 秒。
- 核心活动区以三体引力为主；保守软边界从半径 `2.9` 才开始介入，到 `4.7` 才完全展开，恢复刚度为 `1.5`，允许更大的弹弓轨迹。
- 光球具有有限尺寸的平滑排斥核，防止软化引力在极近距离形成三球重合，同时保留近距离掠过和引力弹弓。
- 全局速度阻尼默认关闭，避免近距离掠过因能量耗散而错误捕获成双星。
- 紧密双星只有在负束缚能状态持续 8 秒、且第三球距离双星质心至少 `1.8` 时才进入再交互阶段；标准测试双星可先自然完成约 5 圈。
- 再交互会在 4 秒内把双星内部引力平滑调整到 `65%`，同时把第三球的成对引力提高到 `150%`，优先让第三球自然扰动双星，而不是强行弹开两球。
- 控制只改变成对力的强度，不直接改写速度；第三球重新接近或双星自然拉开后，会用 3 秒恢复正常参数，并进入 8 秒冷却期。
- 光球离屏较久且仍在向外运动时，恢复范围才会逐步扩大；开始回程后立即恢复为基础软边界，避免回拉力在返程阶段为系统注入额外动能。
- 窄屏使用独立的位移与光晕缩放：物理轨迹会适配可用宽度，光晕仍保留足够尺寸和 Z 轴远近差异，不会因横向空间变窄而一起缩成小点。
- 极端离屏保护按“持续没有返回进展”的时间触发；正常回程即使超过 12 秒也不会被突然淡出重置。
- `app.js` 为每种颜色预生成独立的柔光晕与彩色核心精灵；每帧只缩放、合成两层图像，不重新计算径向渐变。
- 渲染层将物理 Z 坐标按 `2.35×` 做视觉映射，并用连续曲线同步控制透视位移、整体半径、光晕亮度、核心大小、中心亮度和轨迹粗细；光晕半径限制在 `32–250px`，远处更小更柔，近处更大更凝聚。
- 离屏检测保留独立、较保守的 `2.1×` 投影，因此增强纵深只改变画面，不会提前触发物理回拉或压缩运动范围。
- 精灵、投影状态和轨迹均使用固定容量；最高像素比下的六张离屏光球精灵约占 `3.75MiB`，不会随运行时间增长。
- 每颗光球使用 24 点固定容量环形缓冲区绘制短轨迹，轨迹粗细与透明度随深度变化，总状态内存不足 2KB，不会随运行时间增长。
- 页面隐藏时暂停物理计算；返回时清空时间累积，避免一次性补算。
- 开启 `prefers-reduced-motion` 时只显示静态构图。
- Canvas 像素比最高为 `2`，小屏或内存受限设备最高为 `1.5`。

## 主要参数

物理参数集中在 `physics.js` 的 `DEFAULT_PHYSICS_CONFIG`，包括引力常数、软化长度、恢复边界、速度保护和安全半径。视口缩放与离屏进度跟踪集中在 `viewport.js`，相机距离、固定步长和帧补算上限集中在 `app.js` 顶部。
